# Annotation guidelines — pending Phase 6

This is a status placeholder, not an annotation protocol ready for use.
No claims have been annotated and no agreement score exists.

Phase 6 must define evidence scope, atomic-claim boundaries, and the distinctions
between SUPPORTED, CONTRADICTED and UNSUPPORTED, with reviewed examples. Include
numerical, partial-evidence, multi-hop, implicit and semantically similar

kappa, and separately record adjudicated labels and decisions. Select the subset
and agreement procedure before labeling; do not fabricate annotator independence.
